Selenium WebDriver with Java: Complete Beginner Tutorial (2025)

By Automation AI Lab · June 2025 · ⏱ 12 min read

Selenium WebDriver is the most widely used test automation framework in the world. In this tutorial, you'll go from zero to running your first automated browser test using Java and Maven — in under 30 minutes.

What You'll Need

  • Java 21+ (download from Adoptium)
  • Maven 3.9+ (download from maven.apache.org)
  • IntelliJ IDEA Community Edition (free)
  • Google Chrome browser

Step 1 — Create a Maven Project

Open IntelliJ IDEA and create a new Maven project. Use this structure:

selenium-project/
├── pom.xml
└── src/
    └── test/
        └── java/
            └── tests/
                └── FirstTest.java

Step 2 — Add Selenium to pom.xml

Add the Selenium Java dependency and TestNG to your pom.xml:

<dependencies>
  <dependency>
    <groupId>org.seleniumhq.selenium</groupId>
    <artifactId>selenium-java</artifactId>
    <version>4.21.0</version>
  </dependency>
  <dependency>
    <groupId>org.testng</groupId>
    <artifactId>testng</artifactId>
    <version>7.9.0</version>
    <scope>test</scope>
  </dependency>
</dependencies>
✨ Selenium 4 tip: Selenium 4 includes WebDriverManager built-in — you no longer need to manually download ChromeDriver. It's handled automatically.

Step 3 — Write Your First Test

Create src/test/java/tests/FirstTest.java:

package tests;

import org.openqa.selenium.WebDriver;
import org.openqa.selenium.chrome.ChromeDriver;
import org.testng.Assert;
import org.testng.annotations.AfterMethod;
import org.testng.annotations.BeforeMethod;
import org.testng.annotations.Test;

public class FirstTest {

    WebDriver driver;

    @BeforeMethod
    public void setUp() {
        driver = new ChromeDriver();
        driver.manage().window().maximize();
    }

    @Test
    public void verifyGoogleTitle() {
        driver.get("https://www.google.com");
        String title = driver.getTitle();
        Assert.assertEquals(title, "Google");
    }

    @AfterMethod
    public void tearDown() {
        if (driver != null) {
            driver.quit();
        }
    }
}

Step 4 — Run the Test

Right-click on FirstTest.java → Run. Chrome will open automatically, navigate to Google, and the test will pass.

Key Selenium WebDriver Methods

  • driver.get(url) — Navigate to a URL
  • driver.findElement(By.id("id")) — Find element by ID
  • element.click() — Click an element
  • element.sendKeys("text") — Type into a field
  • element.getText() — Get visible text
  • driver.quit() — Close browser and end session

Next Steps

Now that you've written your first test, the natural next steps are:

  2. Implement the Page Object Model pattern
  3. Add TestNG annotations for test organisation
  4. Integrate with Maven Surefire for CI/CD
