Top 30 Selenium Interview Questions & Answers (2025)

By Automation AI Lab · June 2025 · ⏱ 15 min read

These are the most frequently asked Selenium with Java interview questions at companies like TCS, Infosys, Wipro, Cognizant, Capgemini, and product companies. Grouped by difficulty.

🟢 Beginner Level

EasyWhat is Selenium WebDriver and how does it work?
Selenium WebDriver is an open-source API that allows you to control web browsers programmatically. It communicates with browsers via the W3C WebDriver protocol — your Java code sends HTTP commands to a browser driver (ChromeDriver, GeckoDriver), which then controls the browser.
EasyWhat is the difference between findElement() and findElements()?
findElement() returns a single WebElement and throws NoSuchElementException if not found. findElements() returns a List<WebElement> — returns an empty list if nothing is found, never throws an exception. Use findElements() when an element may or may not be present.
EasyWhat locator strategies does Selenium support?
By.id, By.name, By.className, By.tagName, By.linkText, By.partialLinkText, By.cssSelector, By.xpath. Preference order: id > name > CSS selector > XPath. Avoid By.xpath when CSS selector works — XPath is slower and more brittle.
EasyWhat is the difference between driver.close() and driver.quit()?
driver.close() closes the current browser window only. driver.quit() closes all windows and ends the WebDriver session. Always use driver.quit() in @AfterMethod to prevent memory leaks.
EasyHow do you handle dropdowns in Selenium?
Use the Select class for <select> HTML elements: 
Select dropdown = new Select(driver.findElement(By.id("country")));
dropdown.selectByVisibleText("India");
dropdown.selectByValue("IN");
dropdown.selectByIndex(2);
For custom dropdowns (divs/ul), click to open then click the option element directly.

🟡 Intermediate Level

MediumWhat are implicit, explicit and fluent waits?
Implicit wait: Global setting — WebDriver polls for an element for N seconds before throwing NoSuchElementException.

Explicit wait: Waits for a specific condition on a specific element:
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
wait.until(ExpectedConditions.elementToBeClickable(By.id("submit")));
Fluent wait: Like explicit wait but you can configure polling interval and ignore specific exceptions. Never mix implicit + explicit waits — they interact unpredictably.
MediumWhat is the Page Object Model and why use it?
POM is a design pattern where each web page has a corresponding Java class containing its locators and action methods. Benefits: (1) Reduces code duplication — locators defined once, (2) Easier maintenance — when UI changes, update one class, (3) Readable tests — methods like loginPage.loginAs("user", "pass") read like English. See our POM complete guide.
MediumHow do you handle frames/iframes in Selenium?
// Switch to iframe by index
driver.switchTo().frame(0);

// Switch by name or id
driver.switchTo().frame("iframe-name");

// Switch by WebElement
WebElement iframe = driver.findElement(By.id("my-frame"));
driver.switchTo().frame(iframe);

// Switch back to main content
driver.switchTo().defaultContent();
MediumHow do you handle alerts in Selenium?
// Switch to alert
Alert alert = driver.switchTo().alert();

// Get alert text
String message = alert.getText();

// Accept (click OK)
alert.accept();

// Dismiss (click Cancel)
alert.dismiss();

// Type in prompt alert
alert.sendKeys("input text");
alert.accept();
MediumHow do you run Selenium tests in parallel with TestNG?
Configure testng.xml with the parallel attribute: 
<suite name="Suite" parallel="methods" thread-count="4">
  <test name="Test">
    <classes>
      <class name="tests.LoginTest"/>
    </classes>
  </test>
</suite>
Make each test method thread-safe by using ThreadLocal<WebDriver> instead of a shared driver instance.

🔴 Advanced Level

HardHow do you implement ThreadLocal WebDriver for parallel tests?
public class DriverManager {

    private static ThreadLocal<WebDriver> driver = new ThreadLocal<>();

    public static WebDriver getDriver() {
        return driver.get();
    }

    public static void setDriver(WebDriver webDriver) {
        driver.set(webDriver);
    }

    public static void quitDriver() {
        if (driver.get() != null) {
            driver.get().quit();
            driver.remove(); // prevent memory leak
        }
    }
}
Each thread gets its own WebDriver instance — no shared state, no flakiness.
HardWhat is Selenium Grid and when do you use it?
Selenium Grid lets you run tests on multiple machines and browsers simultaneously. A Hub receives test requests; Nodes execute them. Use Grid when: (1) you need cross-browser testing at scale, (2) your test suite takes too long on a single machine, (3) you need to test on different OS/browser combinations. Selenium 4 includes Grid 4 with built-in Docker support.
HardHow do you handle StaleElementReferenceException?
StaleElementReferenceException occurs when a WebElement reference becomes invalid — typically after a page reload or DOM update. Solutions: (1) Re-find the element before each interaction, (2) Use explicit wait with ExpectedConditions.refreshed(), (3) Wrap the interaction in a retry loop: 
public void clickWithRetry(By locator, int maxRetries) {
    for (int i = 0; i < maxRetries; i++) {
        try {
            driver.findElement(locator).click();
            return;
        } catch (StaleElementReferenceException e) {
            if (i == maxRetries - 1) throw e;
        }
    }
}
