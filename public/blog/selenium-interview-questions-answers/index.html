Top 30 Selenium Interview Questions & Answers (2025)

By Automation AI Lab · June 2025 · ⏱ 15 min read

These are the most frequently asked Selenium with Java interview questions at companies like TCS, Infosys, Wipro, Cognizant, and product companies.

🟢 Beginner Level

EasyWhat is Selenium WebDriver and how does it work?
Selenium WebDriver is an open-source API that controls web browsers programmatically via the W3C WebDriver protocol. Your Java code sends HTTP commands to a browser driver (ChromeDriver, GeckoDriver), which controls the browser.
EasyWhat is the difference between findElement() and findElements()?
findElement() returns a single WebElement and throws NoSuchElementException if not found. findElements() returns a List<WebElement> — returns an empty list if nothing found, never throws.
EasyWhat locator strategies does Selenium support?
By.id, By.name, By.className, By.tagName, By.linkText, By.partialLinkText, By.cssSelector, By.xpath. Preference: id > name > CSS selector > XPath.
EasyWhat is the difference between driver.close() and driver.quit()?
driver.close() closes the current window only. driver.quit() closes all windows and ends the session. Always use driver.quit() in @AfterMethod.
EasyHow do you handle dropdowns in Selenium?
Use the Select class for <select> elements: 
Select dropdown = new Select(driver.findElement(By.id("country")));
dropdown.selectByVisibleText("India");
dropdown.selectByValue("IN");
dropdown.selectByIndex(2);
For custom dropdowns (divs/ul), click to open then click the option element.

🟡 Intermediate Level

MediumWhat are implicit, explicit and fluent waits?
Implicit wait: Global — polls for N seconds before throwing NoSuchElementException.

Explicit wait: Waits for a specific condition on a specific element:
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
wait.until(ExpectedConditions.elementToBeClickable(By.id("submit")));
Fluent wait: Like explicit but configures polling interval and ignored exceptions. Never mix implicit + explicit.
MediumWhat is the Page Object Model and why use it?
POM is a design pattern where each web page has a Java class with its locators and actions. Benefits: reduces duplication, easier maintenance, readable tests like loginPage.loginAs("user", "pass"). See our POM complete guide.
MediumHow do you handle frames/iframes in Selenium?
driver.switchTo().frame(0);              // by index
driver.switchTo().frame("iframe-name"); // by name
driver.switchTo().frame(iframeElement); // by WebElement
driver.switchTo().defaultContent();    // back to main
MediumHow do you handle alerts in Selenium?
Alert alert = driver.switchTo().alert();
String message = alert.getText();
alert.accept();           // click OK
alert.dismiss();          // click Cancel
alert.sendKeys("input"); // type in prompt
alert.accept();
MediumHow do you run Selenium tests in parallel with TestNG?
Configure testng.xml: 
<suite name="Suite" parallel="methods" thread-count="4">
  <test name="Test">
    <classes><class name="tests.LoginTest"/></classes>
  </test>
</suite>
Use ThreadLocal<WebDriver> for thread safety.

🔴 Advanced Level

HardHow do you implement ThreadLocal WebDriver for parallel tests?
public class DriverManager {
    private static ThreadLocal<WebDriver> driver = new ThreadLocal<>();
    public static WebDriver getDriver() { return driver.get(); }
    public static void setDriver(WebDriver d) { driver.set(d); }
    public static void quitDriver() {
        if (driver.get() != null) { driver.get().quit(); driver.remove(); }
    }
}
Each thread gets its own WebDriver — no shared state, no flakiness.
HardWhat is Selenium Grid and when do you use it?
Selenium Grid runs tests on multiple machines and browsers simultaneously. A Hub receives requests; Nodes execute them. Use when: cross-browser testing at scale, suite takes too long on one machine, or testing different OS/browser combinations.
HardHow do you handle StaleElementReferenceException?
Occurs when a WebElement reference becomes invalid after a DOM update. Solutions: re-find the element, use ExpectedConditions.refreshed(), or retry: 
public void clickWithRetry(By locator, int maxRetries) {
    for (int i = 0; i < maxRetries; i++) {
        try { driver.findElement(locator).click(); return; }
        catch (StaleElementReferenceException e) {
            if (i == maxRetries - 1) throw e;
        }
    }
}
